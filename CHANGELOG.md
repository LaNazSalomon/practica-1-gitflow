# Changelog

## [1.0.0] - Versión anterior

### Added

- Estructura HTML base del portal del equipo.
- Estilos CSS iniciales con tarjetas de integrantes.
- Página publicada en GitHub Pages.

## [2.0.0] - 2026-06-23

### Added

- Sección de portafolio con proyectos del Equipo 8.
- Sección de contacto con formulario accesible.
- Validación de campos vacíos en el formulario.
- Validación de correo electrónico con expresión regular.
- Guardado de mensajes de contacto en localStorage.
- Botón bonus para mostrar mensajes enviados en la página.
- Variables CSS globales en `:root`.
- Media queries para vista tablet y móvil.
- Transiciones y efectos hover en tarjetas y botones.

### Fixed

- Corrección de atributos `alt` en imágenes.
- Corrección de asociación entre `label`, `input` y `textarea`.
- Resolución de conflicto simulado en el footer entre la rama JS y `main`.
